Visualising a repository diff (draft-holmgren-at-synchronization §4.1 / §4.4.2) as one picture of both MSTs. Entries are classified Kept / Updated / Created / Deleted, with two eXtra sentinel entries 000… and FFF… at layer 128. The old tree contains K+U+D entries, the new tree K+U+C; entries never move, so both trees share one key axis.

Where old and new disagree, the top half of a layer band shows the old tree's node and the bottom half the new tree's. Vertical seams show splits (under a create) and merges (under a delete).

Reading the diagram. Each band is one MST layer (L0 at the bottom, root L128 at the top; the single-child pass-through chain in between is compressed). A bar is a tree node; its width covers the entries and subtrees it contains. Small stems with a dot mark where a lower node hangs as a subtree pointer inside its parent. Dashed outlines mark every node whose hash changes between revisions — exactly the set of MST node blocks a §4.1.1 diff must carry. Note how a create/delete above layer 0 tears or heals the nodes on every layer beneath it along the seam, while an update never changes the node topology at all.
